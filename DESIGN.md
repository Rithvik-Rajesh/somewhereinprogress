# Somewhere In Progress — Design System

## Core Identity

Somewhere In Progress is not a traditional portfolio website.

It is an interactive cinematic personal world focused on:
- storytelling
- atmosphere
- experimentation
- emotional presence
- artistic engineering

The experience should feel:
- calm but alive
- expressive but restrained
- cinematic but human
- immersive but readable
- experimental but intentional

The site should feel like:
"an interactive journal from a curious creative technologist."

---

# Visual Direction

## Primary Influences
- Editorial web design
- Cinematic interfaces
- Interactive storytelling websites
- Architecture studio websites
- Indie game websites
- Fashion/editorial compositions
- Atmospheric photography

---

# Emotional Tone

The site should communicate:
- curiosity
- ambition
- warmth
- movement
- exploration
- humanity
- experimentation
- creativity
- calm confidence

Avoid:
- corporate energy
- startup SaaS aesthetics
- overly futuristic cyberpunk visuals
- excessive neon/glow
- cluttered UI
- over-designed interactions

---

# Typography Philosophy

Typography is a major visual component.

Typography should:
- create rhythm
- define hierarchy
- contribute to atmosphere
- feel cinematic and expressive

Large typography should often function as layout structure.

---

# Font Strategy

## Base Font
Geist

Purpose:
- readability
- modern structure
- clean UI foundation

---

## Accent Font
Instrument Serif

Purpose:
- warmth
- cinematic feel
- editorial atmosphere
- artistic contrast

---

# Typography Rules

## Headlines
- Large
- Bold
- Spacious
- Confident
- Minimal wording

Avoid long headline paragraphs.

---

## Body Text
- Readable
- Soft contrast
- Comfortable spacing
- Slightly larger than default web typography

---

## Layout Typography
Typography may overlap visuals and become part of composition.

Large text overlays are encouraged when intentional.

---

# Color Philosophy

Prefer:
- cinematic blacks
- warm neutrals
- soft whites
- muted accents
- atmospheric gradients

The palette should feel:
- emotional
- cinematic
- mature
- soft
- immersive

Avoid:
- excessive gradients
- rainbow palettes
- harsh saturation
- loud gaming aesthetics

---

# Motion Philosophy

Motion must have purpose.

Motion should:
- guide attention
- create pacing
- support storytelling
- build atmosphere
- enhance immersion

Motion should NOT:
- constantly demand attention
- distract from content
- exist only for decoration

The site should feel alive, not chaotic.

---

# Animation Direction

Preferred motion:
- slow fades
- atmospheric floating
- smooth reveals
- subtle parallax
- cinematic transitions
- intentional staggered movement

Avoid:
- random bouncing
- aggressive spring motion everywhere
- excessive hover spam
- constant looping distractions

---

# Layout Philosophy

The site should feel:
- spacious
- immersive
- cinematic
- layered

Whitespace is important.

Do not overcrowd sections.

Each section should feel distinct like a chapter in a story.

---

# Hero Section Direction

The homepage hero should:
- occupy most of the viewport
- use cinematic imagery/video
- include large expressive typography
- contain atmospheric overlays
- establish emotional tone immediately

The hero should feel immersive and memorable.

---

# Component Philosophy

Components should:
- be reusable
- remain isolated
- support future motion systems
- avoid hardcoded design values

Avoid giant monolithic components.

---

# Design System Rules

All major visual systems should be centralized:
- colors
- typography
- spacing
- motion
- shadows
- layout sizing

The project should support future:
- dynamic themes
- visual experimentation
- rapid iteration

---

# Interaction Philosophy

Interactions should feel:
- tactile
- intentional
- memorable
- playful in moderation

Possible future interactions:
- interactive cursor
- floating overlays
- ambient motion
- scroll storytelling
- horizontal narrative sections
- motion-reactive typography
- 3D hover systems

These should be introduced gradually.

---

# Artistic Philosophy

This project values:
- experimentation
- emotional design
- craftsmanship
- weirdness
- humanity
- imperfection
- iteration

The goal is not to impress everyone.

The goal is to create something expressive and personal.

---

# Important Constraint

Do NOT prematurely optimize visuals.

Build in this order:
1. Structure
2. Typography
3. Layout
4. Content rhythm
5. Motion
6. Advanced effects

Foundation first.
Effects later.

---

# Long-Term Direction

Potential future systems:
- AI assistant
- dynamic themes
- cinematic page transitions
- sound design
- experimental playground
- photography journal
- travel storytelling
- shader effects
- motion-driven storytelling
- interactive timeline

These should integrate naturally into the experience.

---

# Final Guideline

The website should feel unfinished in a beautiful way.

It should communicate:
- growth
- becoming
- curiosity
- experimentation
- movement

The experience should feel human.
