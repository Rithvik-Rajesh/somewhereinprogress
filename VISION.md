# Core Vision

This is not a traditional portfolio website.

The goal is NOT to create:

* a resume website
* a corporate personal brand
* a startup landing page
* a generic developer portfolio

The goal IS to create:

* an immersive personal world
* an artistic interactive experience
* a cinematic storytelling website
* a digital journal of growth, curiosity, ambition, experimentation, and identity

The site should feel alive.
It should feel personal.
It should feel expressive.
It should feel emotionally present.

This project values:

* storytelling
* atmosphere
* pacing
* typography
* motion
* experimentation
* emotion
* intentionality
* craftsmanship

# Design Principles

## 1. Motion Should Have Purpose

Animations should:

* guide attention
* create rhythm
* support storytelling
* enhance emotion

Animations should NOT:

* exist for decoration only
* overwhelm users
* distract from content

The website should use selective memorable movement.

---

## 2. Typography Is A Core Visual Element

Large typography should be used as part of the composition.
Typography is not only for reading.
It is part of the visual storytelling system.

Typography should feel:

* cinematic
* expressive
* elegant
* intentional

---

## 3. Build Systems, Not Chaos

Everything should be centralized and configurable.

The project should support:

* dynamic themes
* centralized typography
* centralized colors
* reusable motion systems
* reusable layout systems
* scalable architecture

Avoid hardcoding styles across components.

---

## 4. Start Static First

Build layouts and structure FIRST.

Then progressively add:

* animations
* interactions
* overlays
* particles
* shaders
* 3D systems
* sound

Do not over-engineer early.

---

## 5. The Website Should Feel Crafted

Attention should exist even in small details:

* transitions
* hover states
* loading states
* spacing
* cursor interactions
* 404 pages
* typography pacing
* section transitions

The goal is artistic craftsmanship.
